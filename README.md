## 📋 What is IDM-Freezer-And-Activator?

IDM-Freezer-And-Activator is a small program built in C++ with a simple and modern window design using Qt. It helps you manage Internet Download Manager (IDM) on your Windows PC. With this tool, you can freeze the lifetime trial, activate IDM, and clean registry entries related to IDM. It keeps your IDM installation well organized and working smoothly.

This program is for anyone using IDM and wants easy control over its trial and activation without complex steps.

## 🔧 Detailed Tool Functions

### Trial Freezer

This freezes the IDM trial clock. Use this if your trial period is ending and you want more time to test IDM without buying a license yet. The program stops IDM from reducing the trial days while frozen.

### Activation Manager

Enter your purchase key here to activate IDM fully. This section lets you check activation status, enter new keys, and deactivate if needed. It helps keep your activation records clean and valid.

### Registry Cleaner

Old IDM records can clutter Windows and cause errors. This tool scans Windows registry for IDM-related entries and safely removes those that could interfere with IDM’s operation or activation.
